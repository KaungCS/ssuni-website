## Things that will bite you if you don't know them

**Vitest is here now, and it is deliberately small.** `node` environment by default; exactly one file
opts into jsdom via a `@vitest-environment` docblock. That is not laziness — issue #32 exempts
presentational components, and a global DOM environment invites the tests this project decided not to
write. **#15 and #18/#30 extend this suite rather than starting their own.**

**Vitest 4, not 5.** 5 requires `@types/node` `^22 || >=24`; this repo pins `^20`. Separately, and not
fixed: the repo pins `@types/node@^20` while Kaung runs Node 24, with no `.nvmrc` or `engines`
anywhere. Pre-existing, latent, and worth an issue eventually — not worth touching three weeks out.

**Money is summed in integer cents.** `19.99 * 3` is `59.97000000000001`. A test holds this line.
Anything that computes money — #15 especially — must not reintroduce decimal arithmetic.

**The subtotal is computed in exactly one place** (`reconcile` in `lib/cart.ts`). If `/cart` and
checkout ever disagree about a price, this is why. Do not add a second implementation in a component.

**`useSyncExternalStore`, not load-effect-plus-save-effect.** The obvious two-effect shape writes `[]`
over the shopper's stored Cart on mount. **The end state recovers**, which is the trap: the first test
written for it passed against the bug. The damage is the transient write, which another tab or a
reload landing in that window reads and keeps. The shipped test records every write and requires none
be empty.

**Three bugs came only from driving the real app**, and no unit test could have caught them: a
non-UUID variant id returning **HTTP 500** from Postgres's uuid cast; a mobile layout pushing the line
price past the page padding because a flex child lacked `min-w-0` (`body.scrollWidth` did *not* catch
this — the screenshot did); and the nav badge reading 99 while the line read 5. **Take screenshots.
The 2026-08-31 handoff says the same thing and it was right again.**

**The dev-server and workerd orphans are real, again.** Stopping the task left `node` holding 3000.
Worse on the workerd side: killing the `workerd` child was useless, because the **`wrangler ... dev`
node parent respawns it** — the port kept coming back with a new PID each time. Kill the parent with
`taskkill //PID <parent> //T //F`. Find it with `Get-CimInstance Win32_Process`. Always confirm both
ports are free before starting a build.

**The Playwright MCP browser does not work on this machine** — it is pinned to real Chrome, and
installing Chrome needs Administrator. `npx playwright install chromium` works, but the MCP server
will not use it. The way through is a scratch script importing `playwright` directly, with the package
installed **in the scratchpad**, not the project. Also: `waitUntil: "networkidle"` never settles
against `wrangler dev` — use `domcontentloaded`.

**A third Product appeared in the catalog** (`og-cool-cap`) since 2026-08-31. The client is adding
rows between sessions, exactly as `CLAUDE.md` warns. Nothing broke, because no test asserts a count.
Keep it that way.
